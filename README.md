# Reflexión del Proyecto - Chatbot NetAsistente

### 1. ¿Qué proceso automatiza el chatbot?
El chatbot automatiza el primer diagnóstico y reporte de incidencias técnicas de servicio de internet, guiando al cliente en soluciones básicas antes de canalizarlo.

### 2. ¿Qué indicador mejoraría?
Mejora el tiempo promedio de resolución (MTTR), al solucionar problemas comunes en el primer contacto sin requerir la intervención de un técnico.

### 3. ¿En qué situaciones debe escalar a un humano y por qué?
Debe escalar a un humano en casos de cobros indebidos o cambios de dirección fiscal/de domicilio, ya que los problemas de facturación afectan directamente la confianza del cliente y requieren validación manual y empatía.

### 4. ¿Qué tipo de usuario no encuentra su opción y cómo se atiende?
Aquellos usuarios que tienen problemas con equipos de terceros o instalaciones especiales no estándar. Se les atiende canalizándolos mediante la opción de visita técnica para una revisión personalizada.
